# @design-tokens/core

Scan, cluster, name, generate, and rewrite design tokens. Used by the [Design Token Extractor & Migrator](https://github.com/bobrowsse-tech/design-token-extractor) CLI and VS Code extension.

```bash
npm install @design-tokens/core
```

Most people should use [`@design-tokens/cli`](https://www.npmjs.com/package/@design-tokens/cli) or the VS Code extension instead of importing this package directly.
